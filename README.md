# Psalmist releases

Download the latest **Psalmist** Android app from
**[Releases](https://github.com/coxy-trophy/psalmist-releases/releases/latest)**.

Psalmist is an unofficial music app for the songs published on jw.org: every album
and soundtrack, synced lyrics (with a second language if you like), music videos,
this week's meeting songs with reminders, sing-along, offline downloads, Android
Auto and Chromecast. Music, artwork and lyrics stream from jw.org; nothing is
stored in or hosted by the app.

## Install

1. Open the [latest release](https://github.com/coxy-trophy/psalmist-releases/releases/latest)
   on your Android phone and download the `.apk` file.
2. Open it. If Android asks, allow your browser or file manager to install apps.
3. Tap **Install**.

Requires Android 8.0 or newer.

## Updates

Psalmist checks this page for new versions. When one is available it shows
**Update available**; tap **Update**, then **Install**. Your playlists, likes and
downloads are kept.

If you installed a copy from before version 2.2, install 2.2 from here once by hand;
after that, updates come to you in the app.
